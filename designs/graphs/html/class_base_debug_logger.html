bool BaseDebugLogger::activate ( bool retry)
overrideprotected

Activate the debug logger. If the SD card is not ready for writing, then immediately return false. Otherwise, create a new temporary log file and return true.

Parameters

◆ handle_produced_work()

int8_t BaseDebugLogger::handle_produced_work ( const worker_map_t & workers)
finalprotected

Handle produced work. If the log aggregator has new data, and the sd card is ready, then write the line to the log file. If the log file is currently temporary, then use the rtc to rename the log file. If the write succeeds, then increment _total and return e_handler_data_handled. If there is no new data, then return e_handler_idle.
